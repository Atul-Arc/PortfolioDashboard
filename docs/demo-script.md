# BFSI Demo Walkthrough Script

## Objective

Demonstrate a professional wealth-management dashboard experience using enterprise-like
mock data and decision-oriented reporting.

## Walkthrough Order

1. Open executive dashboard and highlight:
- Total invested amount
- Current portfolio value
- Total gain/loss
- Portfolio return
- Risk score

2. Explain holdings composition table:
- Instrument and asset type distribution
- Positive and negative return examples
- Exposure concentration insight

3. Review analytics section:
- Asset allocation pie chart for concentration
- Portfolio growth trend chart for trajectory
- Gain/loss by asset chart for attribution

4. Present risk analytics:
- Risk band interpretation
- Concentration warning
- Suggested advisory attention area

## Validation Checklist

- Desktop and tablet views are both readable and usable.
- Metrics are consistent with holdings totals.
- Chart insights align with executive summary narrative.
- Data source is clearly identified as enterprise mock data.
